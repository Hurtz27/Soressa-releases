# Soressa Releases & Updates 🚀

Repositorio oficial de distribución y manifiesto de actualizaciones automáticas para **Soressa** (Sistema de Calificaciones y Gestión Escolar).

## Estructura
- `updater.json`: Manifiesto consultado por la aplicación cliente para detectar e instalar nuevas versiones.
- **Releases**: Almacén de binarios e instaladores firmados (`.msi`, `.exe`, `.sig`).
